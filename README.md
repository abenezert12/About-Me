## 🎨 React + Motion Example

This section shows the exact React component pattern I use to deliver polished motion-driven UI.

> GitHub README cannot render React or motion effects directly, but this sample reflects the actual frontend experience I build in real projects.

**Motion preview concept**

- Animated hero headline with smooth entrance motion
- Motion-driven CTA card with scale and fade effects
- Modern UI built with `Framer Motion` and Tailwind-like styling

```jsx
import { motion } from 'framer-motion';

export default function HeroBanner() {
  return (
    <section className="hero container mx-auto px-6 py-16 text-center">
      <motion.div
        initial={{ opacity: 0, y: 40 }}
        animate={{ opacity: 1, y: 0 }}
        transition={{ duration: 0.8, ease: 'easeOut' }}
        className="mb-8"
      >
        <p className="text-sm uppercase tracking-[0.4em] text-slate-500">
          Frontend + Motion Design
        </p>
        <h1 className="mt-4 text-5xl font-bold text-slate-900">
          I build animated React experiences
        </h1>
        <p className="mt-4 max-w-2xl mx-auto text-lg text-slate-600">
          Crafting polished interfaces with smooth transitions, responsive layouts, and meaningful motion.
        </p>
      </motion.div>

      <motion.div
        initial={{ scale: 0.92, opacity: 0 }}
        animate={{ scale: 1, opacity: 1 }}
        transition={{ duration: 0.7, delay: 0.2 }}
        className="inline-flex rounded-3xl bg-slate-950 px-8 py-4 text-white shadow-xl"
      >
        <span>Explore my work</span>
      </motion.div>
    </section>
  );
}
```
